# Evidence rubric

Each official criterion is worth 20 points. Internal target 94; target is not a result or a prediction. Require observed evidence for every point; pending publication/video and untested model behavior reduce the final score.

| Criterion | Evidence required |
|---|---|
| Technological implementation | Real MAF run, validated data, test reports, maintainable modules |
| Agentic design & innovation | Distinct specialists, typed handoffs, verification, actual recovery, measured baseline |
| Real-world impact | Useful personas, broadcast contracts, reproducibility, explicit constraints |
| UX & presentation | Six working views, real screenshots, responsive browser checks, functioning demo video |
| Category adherence | Ingest, interpret, explain, render, personalize; original synthetic data and multilingual output |

Critical tests and basic eligibility take precedence over numeric score. Final evidence and weaknesses are recorded in SCORECARD_FINAL.md.
