The axe scan covers all seven views and reports no serious/critical findings in that scan; it is not a complete accessibility certification.
- **1 additional browser journey passed against an actual separate minimal Render-profile backend.** That environment was freshly installed from requirements-render.txt and contains no Foundry SDK, ONNX model, OpenAI provider or NumPy. The configured frontend auto-connected, correctly disabled local LLM inference, ran the real deterministic Microsoft workflow and recomputed the Champions League historical model. This ran locally on Windows with Render settings; it is not a claim that an authenticated Render deployment or Linux build has been tested.
- **5 Google Apps Script unit checks passed in Node.** They test one health GET, HTTP failure, non-JSON cold-start response, unhealthy status and an unconfigured URL. No real Apps Script account authorization or scheduled trigger has been executed; you set the trigger.
- **Historical model backtest:** 2,283 held-out 2025–26 matches, 52.17% accuracy versus 45.38% constant-frequency baseline. This measures the result model, separately from the five-agent narrative comparison.
- **Existing local-agent evidence:** five actual Foundry Local model runs and model-backed recovery are retained. Those LLM runs were executed in the original build; this follow-up did not claim new LLM training. The added model is a small statistical result model trained on real results.
- **Build/audits/assets:** Vite production build, original core latency measurements, dependency audits, credential-pattern scan and real 105-second screen recording are reported separately. Newly edited deployment configs and source data are included in the final rechecks and package.
