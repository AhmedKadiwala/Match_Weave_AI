# Before uploading — do these in order

1. **Local check:** double-click `RUN_MATCHWEAVE.cmd`. It opens the app after the combined UI/API server is ready. Keep that window open. Open **Real match lab** and **Agent intelligence**. A `127.0.0.1` link is local, not a deployed public URL.
2. **GitHub:** upload/push this repository's source to a public GitHub repository. Upload `backend/`, `frontend/`, `datasets/`, `models/`, scripts, manifests and instructions together. Do not upload `.venv`, `node_modules`, `.env` or `runtime`. `frontend/public/history` and `frontend/public/artifacts` **must be included**; they contain the actual datasets/predictions/recorded workflows used by the public demo. If using the prepared source ZIP, extract it and upload/push the extracted contents; do not upload only the ZIP itself.
3. **Render backend first:** create a **Python Web Service → Free** from the repository. Root Directory: blank/repository root. Build: `pip install -r requirements-render.txt`. Start: `python -m uvicorn backend.app.main:app --host 0.0.0.0 --port $PORT --workers 1`. Health path: `/api/health`. Set `PYTHON_VERSION=3.14.7`, `MATCHWEAVE_DEPLOYMENT=render`, `MATCHWEAVE_DB=/tmp/matchweave/matchweave.db`. `render.yaml` is also provided. No local-model runtime or paid API is required by Render.
4. **Vercel frontend:** import the same repository. Root Directory **frontend**. Framework **Vite**. Install `npm ci`; Build `npm run build`; Output `dist`. Set `VITE_API_URL` to the **actual Render HTTPS origin**, without `/api`. Use your personal Hobby project; do not enable a Pro trial or paid add-ons. Deploy.
5. **Connect the two:** copy the literal Vercel production origin into Render's `MATCHWEAVE_CORS_ORIGINS`. Use exact `https://...vercel.app`, not `*`, a path, or a guessed domain. Save and let Render redeploy. Changing `VITE_API_URL` later requires a new Vercel deployment.
6. **Five-minute ping:** paste `GOOGLE_KEEP_ALIVE.gs` into Google Apps Script. Replace `BACKEND_URL` with the actual Render origin. Run `pingBackend` once and authorize its URL-fetch permission. Add Trigger → `pingBackend` → Time-driven → Minutes timer → Every **5 minutes**. No web-app deployment, Gmail permissions or inference call is needed.
7. **Before submitting:** use an incognito/signed-out browser. Verify the seven views, real-data season filter, evidence drawer, new hosted deterministic workflow, real-model recompute and overlay download. Check that local-model inference is disabled in hosted mode and recorded runs are labeled. Upload the video and fill in the real public URLs in SUBMISSION.md. The updated 105-second video includes Real match lab, actual historical-model recomputation and the original source-verification workflow.

Detailed settings and troubleshooting: [DEPLOY_TO_VERCEL_RENDER.md](DEPLOY_TO_VERCEL_RENDER.md).

Five-minute pings reduce idle spin-down but do not guarantee uptime. Render Free hours are shared across your workspace, and SQLite is ephemeral. The recorded frontend stays usable when the backend is cold or unavailable. [Render limits](https://render.com/docs/free), [Vercel Hobby](https://vercel.com/docs/plans/hobby), [Google trigger API](https://developers.google.com/apps-script/reference/script/clock-trigger-builder).
