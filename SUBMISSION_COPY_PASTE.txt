PROJECT TITLE
MATCHWEAVE AI

TAGLINE
Evidence you can see. Stories made for you.

SHORT PITCH
MatchWeave AI transforms football events into evidence-checked stories, personalized fan experiences and timed broadcast graphics using Microsoft Agent Framework and local AI, with a separate model trained on real historical match results.

PROJECT DESCRIPTION
Football fans see the score, but understanding why a match is changing requires context. Analysts need supporting evidence, while broadcast producers need concise graphics they can time and reuse. MatchWeave AI connects these needs through one workflow: ingest, interpret, explain, render and personalize.

The application processes 9,887 reproducible synthetic events across five fictional matches. Seven views support match replay, tactical exploration, player focus, automated recaps, agent inspection, broadcast graphics and historical analysis. Fans, analysts and producers receive different presentations of the same verified facts, with English, Hindi and Spanish templates and club/player preferences.

Microsoft Agent Framework coordinates specialist agents through parallel analysis, shared results, numerical verification and conditional repair. Microsoft Foundry Local runs the pretrained Qwen2.5 1.5B language model on the computer, without a paid cloud-model API. The agents select constrained claims and layouts; canonical event calculations check numerical claims before publication. Viewers can inspect the supporting event IDs and see an intentionally incorrect claim rejected, repaired and checked again. The studio exports timed JSON containing the approved facts and evidence for graphics workflows.

A separate Real match lab includes 12,372 completed results, plus two cancelled fixtures, from January 2021 through 2025–26 across the European big five leagues and Champions League, Europa League and Conference League. Qualifying rounds and 2026–27 are excluded. A locally trained logistic-regression model estimates home-win, draw and away-win probabilities from pre-match features. Its frozen evaluation model achieved 52.17% accuracy on 2,283 held-out 2025–26 matches, compared with a 45.38% frequency baseline. Historical results remain separate from synthetic tactical events.

The React/TypeScript frontend connects to a FastAPI/Python backend. Fresh local language-model inference, recorded AI runs and deterministic verification are explicitly labeled. The default demo includes recorded local-model traces and fresh historical-model inference; optional Foundry setup enables new language-model calls. Executed checks include 45 backend tests, 12 browser journeys and five health-ping checks. Source, datasets, model weights, setup instructions, reports and the 105-second demonstration are included in the public repository.

TESTING / RUN INSTRUCTIONS — IF THE FORM ASKS
1. Open https://github.com/AhmedKadiwala/Match_Weave_AI and follow README.md. The executed environment used Windows 11, Python 3.14.7 and Node.js 24.19.0.
2. Clone or download and extract the repository. Double-click RUN_MATCHWEAVE.cmd. First launch installs dependencies and builds the frontend, so internet access is needed. No paid API key is required.
3. Wait for http://127.0.0.1:8000/ to open and keep the terminal running. Explore the match views, audience/language choices, evidence drawer and broadcast JSON export.
4. In Agent intelligence, inspect actual recorded local-model traces and the repair example. Select the deterministic provider and run a fresh workflow through the Python backend.
5. In Real match lab, select a historical fixture, inspect its source and evaluation label, then recompute its result-model probabilities through the backend.
6. For optional fresh language-model inference, open a second terminal in the project folder and run .\.venv\Scripts\python.exe -m scripts.local_model. Wait for Foundry Local to be ready, select the local model in Agent intelligence and run a workflow. This downloads model weights if missing. Default startup does not download them.
