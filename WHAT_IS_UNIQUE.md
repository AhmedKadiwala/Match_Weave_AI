# What makes MatchWeave distinctive

The central feature is **one evidence record producing different, fact-consistent experiences**. A fan gets a short explanation, an analyst gets windows/change/sample limits, and a producer gets a timed graphic payload. Switching language or audience does not change the approved numbers.

1. **Traceable publication:** every synthetic tactical story cites the exact events supporting its count. The verifier checks the full source set and independently recounts it before output is published.
2. **Visible failure recovery:** a deliberately incorrect +99 claim is rejected, repaired from the canonical log and checked again. Both the deterministic test and an actual local-model execution are preserved.
3. **Real Microsoft orchestration:** five actual Foundry-backed agents run through a typed Microsoft Agent Framework graph, with parallel analysis, reconciliation, conditional repair and per-step tool/timing/fallback records. Executor-scheduled tools and model-requested tools are labeled separately.
4. **Broadcast output, not just prose:** the studio exports JSON containing match timing, layout, persona, language, verification status and source IDs; the preview and exported values share the same approved claim.
5. **Usable public replay:** the Vercel frontend carries real recorded runs and data. A cold or unavailable Render backend does not erase the demo. Render still executes fresh deterministic Microsoft workflows and the trained historical result model.
6. **Real-data extension with honest ML:** 12,372 completed matches across eight main competitions; 2026–27 excluded; a frozen chronological evaluation and a separate all-data refit. A separate Real match lab shows source records, estimates and coverage instead of pretending final scores contain tracking events.

These are implemented differentiators, not a claim that nobody else has built a similar idea. Current boundaries: local-language generation is constrained by templates, real-result analysis is historical rather than a live licensed event feed, the simulation is simplified, the model is exploratory, and public deployment still requires your account actions. Measured comparisons and test reports are provided; an award or future accuracy is not guaranteed.
